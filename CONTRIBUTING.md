# Contributing to Beamfall Enrichment

Thank you for your interest in improving Beamfall Enrichment.

External contributions are accepted only from contributors with a signed Beamfall Contributor
License Agreement on file. Before you open a pull request or send a patch:

1. Read the Beamfall Contributor License Agreement in [CLA.md](CLA.md).
2. Sign it as an individual contributor, or as an authorized representative when you contribute on
   behalf of an organization.
3. Send the signed CLA to the Beamfall project.
4. Wait for written confirmation that your CLA has been accepted.

Once your CLA is accepted, run `script/gate.sh` before you submit a change so formatting, vet,
tests, coverage floors and lint all pass locally.
